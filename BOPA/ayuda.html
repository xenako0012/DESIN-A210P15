BUSCADOR

Cómo realizar una búsqueda

¿Cómo puedo encontrar una publicación?

Accede al apartado «Buscar» y escribe una palabra relacionada con el contenido que quieres encontrar. Puedes buscar por conceptos, organismos, tipos de publicación o términos concretos.

¿Puedo combinar varios filtros?

Sí. Puedes combinar diferentes filtros para reducir el número de resultados. Por ejemplo, puedes seleccionar una Consejería y limitar la búsqueda a un determinado periodo de publicación.

¿Qué tipos de publicaciones puedo buscar?

El buscador permite localizar diferentes tipos de publicaciones, como decretos, resoluciones, oposiciones y concursos, subvenciones y anuncios.

RESULTADOS

Cómo interpretar los resultados

¿Qué información aparece en cada resultado?

Cada resultado muestra el tipo de publicación, su fecha, título, órgano emisor, número del BOPA y una breve descripción para que puedas identificar el documento antes de abrirlo.

¿Qué significa «Vista previa»?

La vista previa permite consultar rápidamente la información principal de una publicación sin abandonar la página de resultados.

¿Cómo puedo ordenar los resultados?

Puedes utilizar el selector de ordenación situado encima de los resultados para consultar las publicaciones por relevancia, fecha o número de consultas.

ACCESIBILIDAD

Un BOPA más fácil de consultar

El rediseño busca facilitar la consulta del boletín mediante una estructura clara, una jerarquía visual sencilla y controles identificables.

  • Contraste suficiente entre texto y fondo.
  • Estructura de contenidos clara.
  • Botones y enlaces diferenciados.
  • Diseño adaptable a diferentes tamaños de pantalla.
  • Información organizada para reducir la carga cognitiva.
